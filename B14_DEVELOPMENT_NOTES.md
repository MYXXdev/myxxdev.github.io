# MYbloXX 2.0 - Native Redesign & RootHide Recovery (B14 development)

This is PRIVATE development source. **The B14 code is not yet compiled or installed-test verified.** Keep the on-device B12/B13 + CC v0.2.1 installation as the known-working release until an iOS build succeeds and receives a real device test.

## Rewritten Settings
- New adaptive `MYBModernController` using native inset-grouped UIKit rows and scalable section layout.
- Existing root-controller fixed frame glass headers removed.
- New `MYBRulesController` built on native UIKit grouped lists with add/edit and native swipe-to-delete.
- Original MYXXdev names and blocking modes preserved.
- PreferenceLoader entry name and icon declared; reproducible icon and matching CCSupport glyph generated by `tools/generate-icons.swift`.
- RootHide repair command visible from the Settings home page, and an explicit NEEDS REPAIR status when the persisted mode is enabled but the managed link is missing.

## RootHide persistence
- The native helper determines its own jailbreak root directory instead of relying exclusively on `/var/jb`.
- The active proxy plist and user-enabled state are stored in `/var/mobile/Library/MYbloXX/`.
- An existing MYbloXX-owned `/var/jb` symlink can be safely migrated, while unrelated managed policies are protected.
- `restore` reconstructs the owned proxy link after rejailbreaking, without activating the tweak if its last saved state was disabled.
- A LaunchDaemon is included for post-jailbreak bootstrap recovery. This daemon needs validation against actual Dopamine RootHide launchd behavior.
- A dedicated `build-roothide.yml` uses RootHide Theos and `THEOS_PACKAGE_SCHEME=roothide` for ARM64e.
